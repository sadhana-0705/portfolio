## 🚀 Getting Started

### Prerequisites

* Node.js 18+
* npm

### Installation

```bash
git clone https://github.com/sadhana-0705/<your-portfolio-repo>.git
cd <your-portfolio-repo>
npm install
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
